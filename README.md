## Flagship Project

### VouchIt — the thing that vouches for your AI-generated code

> "The scarce resource is no longer writing code — it's vouching for it."

The verification layer for AI-generated code. A CLI that runs a fleet of audit agents (security, edge, ops, quality) over any codebase or plan, and returns a ranked risk/quality report with a full audit trail.

- **Model-agnostic** — works with any LLM, includes free models, runs fully local, zero capital
- **Audit trail** — every finding is traceable; run-diff shows improvement between versions
- **CI-gate ready** — exports a gate artifact your pipeline can block on
